Materi Pemrograman Berorientasi Objek

1. Konstruktor

Konstruktor adalah fungsi khusus yang dipanggil saat objek dibuat. Fungsinya untuk menyiapkan nilai awal variabel. Tanpa konstruktor, kita harus mengisi data satu per satu setelah objek dibuat.

Jenis utama di Dart: Konstruktor Default, Berparameter, dan Named Constructor.

// Contoh Konstruktor Berparameter
class Product {
  String name;
  double price;

  // Inisialisasi instan
  Product(this.name, this.price);
}

2. Enkapsulasi

Enkapsulasi adalah teknik "membungkus" data agar tidak bisa diakses sembarangan. Di Dart, kita menggunakan simbol _ (underscore) untuk membuat variabel menjadi private. Akses hanya diberikan melalui metode getter dan setter untuk menjaga validitas data.

class User {
  String _username; // Private

  User(this._username);

  // Getter: untuk membaca data
  String get username => _username;

  // Setter: untuk mengubah data dengan aturan
  set username(String value) {
    if (value.length > 3) _username = value;
  }
}
