Materi PBO: Konstruktor & Enkapsulasi

1. Konstruktor

Konstruktor adalah metode khusus yang dipanggil otomatis saat objek dibuat untuk inisialisasi awal.


class Produk {
  String nama;
  double harga;

  // Konstruktor berparameter
  Produk(this.nama, this.harga);
}

2. Enkapsulasi

Enkapsulasi menyembunyikan data sensitif menggunakan _ (underscore) agar bersifat private.


class Pengguna {
  String _nama; // Private

  Pengguna(this._nama);

  // Getter
  String get nama => _nama;
}
